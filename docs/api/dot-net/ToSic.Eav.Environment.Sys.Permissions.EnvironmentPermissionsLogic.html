EnvironmentAllows(List<Grants>, EnvironmentPermissionOptions, Func<bool>, Func<bool>)

This should evaluate the grants and decide if the environment approves any of these grants. Note that in many cases the implementation will simply check if the environment provides edit permissions, but it can really check the grants required and compare each one with the environment.
