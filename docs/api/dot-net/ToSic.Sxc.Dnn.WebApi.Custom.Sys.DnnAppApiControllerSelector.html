This is a .net Framework controller selector to handle dynamically compiled controllers inside 2sxc apps.

[InternalApi_DoNotUse_MayChangeWithoutNotice("only made public for docs")]
public class DnnAppApiControllerSelector
Inheritance
object
DnnAppApiControllerSelector

Remarks

It will be registered in the ServicesContainer to override the previous selector. It will

  1. check if it's responsible (based on url)
  2. and if yes, hand off to DnnAppApiControllerService to compile / run the app-specific api controllers
  3. otherwise hand processing back to next api controller up-stream

GetControllerMapping()

Returns a map, keyed by controller string, of all System.Web.Http.Controllers.HttpControllerDescriptor that the selector can select. This is primarily called by System.Web.Http.Description.IApiExplorer to discover all the possible controllers in the system.
