# Run an Angular App in 2sxc and Dnn

[!include[](~/pages/basics/stack/_shared-float-summary.md)]
<style>.context-box-summary .spa-all { visibility: visible; } </style>

Use the [Angular Loader extension](xref:Extensions.AppExtensions.By2sxc.AngularLoader.Index) to load a built Angular application in a 2sxc app.

The extension handles the runtime integration, including:

1. Loading the scripts and styles generated by Angular.
1. Rendering the Angular root element.
1. Loading `live`, `staging`, or local-development editions when needed.
1. Connecting a local Angular development server for hot reload.

## Recommended Setup

1. [Install the Angular Loader extension](xref:Extensions.AppExtensions.Install.Index) in your 2sxc app.
1. Follow the [Angular Loader instructions](xref:Extensions.AppExtensions.By2sxc.AngularLoader.Index) to configure the build path, Angular root tag, and optional editions.
1. Configure [sxc-angular](xref:JsCode.Angular.DnnSxcAngular.Install) inside the Angular application when it needs 2sxc data, queries, WebAPIs, context, or edit toolbars.

For a complete working example, install the [Angular Template App](xref:JsCode.Angular.TemplateApp) or browse its [source repository](xref:App.AngularTemplate.Git).

> [!TIP]
> The Angular Loader documentation is the authoritative guide for runtime integration. Keep loader configuration there instead of copying its implementation into your own Razor code.
