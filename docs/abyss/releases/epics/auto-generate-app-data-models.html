Epic: Auto-Generate App Data Models

Entity schemas can be used to generate models in the App code. Now we want to do this automatically, as the schema changes.

But it's important that the developer actively chose to do this, because some changes (such as removing or renaming fields) can result in broken code.

Planned Improvements

As of now, the system feels a bit sluggish, because the code runs synchronously every time a relevant schema change is detected. Optimizing this process or introducing asynchronous handling could improve performance. This may be a bit tricky, as async processing could break because the dependency-provider may be deleted during async execution.
